# Carleton Mail Delivery Robot

This is an engineering capstone project for the 2025-2026 year at Carleton University.

The purpose of the mail-delivery robot project is to introduce reliable mail-delivery inside the tunnels of Carleton University. This would provide Carleton University with an alternative method to deliver mail to other buildings and faculty. It would also give faculty more free time to focus on other important tasks.
The current project explores the use of large language model (LLM) agents to program an iRobot for mail delivery in the Carleton tunnels, with an emphasis on maximizing LLM involvement within the system. The LLM may be used for tasks such as processing sensor input, planning, and action execution. Each iteration of the system is evaluated using a dashboard that displays performance metrics, alongside a simulation tool to support testing and analysis.
